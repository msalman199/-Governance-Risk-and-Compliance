# 🛡️ Governance, Risk and Compliance (GRC)

## 📌 Purpose of This Repository

This repository contains practical **Governance, Risk, and Compliance (GRC)** labs and projects developed as part of the **Al-Razzaq Programme**.

The main purpose of this repository is to demonstrate practical knowledge of **cybersecurity governance, risk management, compliance, security controls, assessments, and regulatory frameworks**.

The projects focus on applying security and compliance concepts in realistic technical environments rather than only studying them theoretically.

---

## 🎯 What This Repository Covers

This repository includes practical work related to:

* 🏛️ Governance and security policies
* ⚠️ Risk management and risk assessment
* 🔐 Security controls and control implementation
* 📋 Security control assessments
* 📝 POA&M development
* 🏢 Business Continuity Management (BCM)
* 🔄 Disaster Recovery (DR)
* 📊 FIPS 199 system categorization
* 🛡️ NIST SP 800-53 controls
* 🔎 NIST Risk Management Framework (RMF)
* 📈 Continuous monitoring
* 🧪 Security testing and evidence collection
* 🔐 ISO 27001
* 🌐 NIST Cybersecurity Framework
* 🔒 Privacy and DPIA
* 🤝 Third-Party Risk Management
* 📑 Regulatory compliance mapping
* 📊 Risk quantification
* 🤖 AI Governance
